# T-Drive Analyzer

Вебзастосунок для аналізу GPS-треків T-Drive, моделювання дорожніх умов і генерації розширених транспортних даних.

## Швидкий старт

1. Завантажте репозиторій через **Code → Download ZIP** і розпакуйте архів.
2. Відкрийте `traffic_simulator.html` у сучасному браузері.
3. Завантажте один або кілька `.txt`-файлів із папки `proj` через панель завантаження застосунку.
4. Перегляньте статистику, задайте параметри симуляції та експортуйте результати.

Для завантаження Chart.js із CDN потрібне підключення до Інтернету. Окремий сервер або встановлення npm-пакетів не потрібні.

## Файли проєкту

- `traffic_simulator.html` — застосунок (HTML, CSS і JavaScript).
- `proj/` — надані вхідні файли GPS-треків.
- [Інструкція користувача](docs/Інструкція_користувача.md) — докладний опис роботи зі скриншотами.
- `docs/screenshots/` — ілюстрації до інструкції.

## Формат вхідних даних

Кожен рядок містить поля `ідентифікатор,часова мітка,довгота,широта`, розділені комами. Часова мітка має формат `YYYY-MM-DD HH:mm:ss`.
